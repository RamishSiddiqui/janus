# Keyboard shortcuts

Use `Cmd` instead of `Ctrl` on a Mac.

## Anywhere

| Keys | Action |
|---|---|
| `Ctrl+N` | Go to the chat start page (new chat). |
| `Ctrl+B` | Show or hide the sidebar. On a phone it opens and closes the menu drawer. |
| `Esc` | Close the open menu, dialog or panel, and leave the field you are typing in. |

## Chat box

| Keys | Action |
|---|---|
| `Enter` | Send the message. |
| `Shift+Enter` | New line. |

## Messages

| Keys | Action |
|---|---|
| `Left` / `Right` | On a message with several timelines, move to the previous or next one. |

## Search (sidebar)

| Keys | Action |
|---|---|
| `Enter` | Search (two or more characters). |
| `Up` / `Down` | Move through the results. |
| `Enter` on a result | Open it. |
| `Esc` | Clear and close. |

## Panels and lists

| Keys | Action |
|---|---|
| `Left` / `Right` on the context panel's divider | Make the panel wider or narrower. |
| `Enter` or `Space` on a model row | Open its details. |
| `Enter` on a card | Open that character or persona. |
| `Enter` / `Esc` while renaming a chat | Save / cancel the new name. |
| `Esc` in the memory panel, scene gallery, cast views or a picker | Close it. |

## Browser and phone

Everything above works in a browser with a keyboard. On a phone, use the menu button at the top left to open the sidebar.
