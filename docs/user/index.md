# User guide

Everything you need to use Janus, from the first launch to the details of each feature.

## Start here

- {doc}`getting-started`: connect a model and start your first chat.
- {doc}`chatting`: sending messages, timelines, branching, attachments.
- {doc}`troubleshooting` and {doc}`faq` when something is not working.
