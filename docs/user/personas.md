# Personas

A persona is **you** in the story: the character you play. Where a character card describes who you talk to, a persona describes who is talking.

## Creating and managing personas

Open **Personas** in the sidebar.

- **Create** asks for a **Name** and builds the persona. Open it to fill in a description and personality the same way as a character.
- **Import** reads a persona from a character-card PNG, the same format characters use.
- **Search** filters the list. The bin deletes a persona (it goes to the [Trash](data-and-privacy.md#trash)).
- A persona can have a portrait: upload one, or generate one if you have an image provider.

## Using a persona in a chat

- Each chat has a persona picker in the **Persona** panel of the chat tools (the person icon in the chat header). Choose **None** to chat as a generic "User".
- The persona you pick is described to the model in every prompt, and `{{user}}` in character text is replaced with its name.
- When you start a chat from the gallery, the persona you last selected is used.

Personas are per account.
