# Name and trademark policy

"Janus" and the Janus logo identify the official app published from this repository. The source code is free software under the AGPL-3.0, and you can do almost anything with it. This policy only covers the **name and logo**, so that people can tell the official app from copies.

## You can

- Say your project is **based on** or **a fork of** Janus, and link to this repository.
- Use the name to describe the official app accurately (for example in a review, a tutorial or an article).
- Run Janus for yourself, your team or your company.

## Please don't

- Distribute a modified or repackaged build under the name "Janus", or with the Janus logo, in a way that suggests it is the official app or is endorsed by the project. Give a modified version its own name and logo.
- Offer downloads of "Janus" from anywhere other than this repository's Releases page and describe them as official.
- Remove or hide the AGPL-3.0 notice, or say a copy is signed or verified by the project when it is not.

Installed copies of the official app only accept updates signed with the project's key, so a modified build cannot be updated from the official releases and should not look like one.

## Reporting

If a site or an app uses the name or logo to pass a modified copy off as official, report it privately as described in [SECURITY.md](SECURITY.md).

*This is a plain-language policy and not legal advice. Registering the name as a trademark is a separate step the project has not taken yet.*
